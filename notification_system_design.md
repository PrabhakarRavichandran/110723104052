# Notification System Design

## Overview
This project is a notification management system with:

- Backend Priority Inbox Logic (Python)
- Frontend Dashboard (Next.js + TypeScript)
- Logging Middleware Integration

---

# Features

## Stage 1 (Backend)
- Categorize notifications by priority
- Mark notifications as read/unread
- Store notifications in memory
- Filter high-priority notifications

## Stage 2 (Frontend)
- Modern UI using Material UI
- Authentication Token Dialog
- Notification Cards
- Priority Notifications Page
- Read Status Hook
- Context API for Authentication
